# 中国大陆线索

按 `observe.md` 的层级排：平台元数据 → 文字车牌 → 车辆交通 → 基础设施 → 气候物候 → 地形水系 → 城市形态。

## 平台与元数据（全部是待验证的假设）

### 评论/发帖的 IP 属地
- 看什么：抖音、小红书、微博评论和帖子旁的省份（国外显示国家），连同发帖日期
- 指向：发帖那一刻人在哪个省，不是照片在哪
- 强度：弱；叙述是"今天拍、今天发"且水印时间和发帖时间一致时升为中
- 反例：旅途中发帖、老照片、代理上网（v006：照片在 IP 省的邻省）；出题人的"不在某地"本身也是待核的假设。和画面冲突时保留"本省相符地块 + 邻省"，不整省排除
- 来源：v004 v006 v010 v011

### 照片时间水印 / EXIF 时间
- 看什么：画面角落的日期时间水印；`exif.py` 读出的 DateTimeOriginal
- 指向：拍摄月份和时刻 → 物候判断、太阳计算
- 强度：中（水印可被相机设置错；EXIF 能被改）
- 反例：翻拍、转发后抹掉元数据；相机时区没设
- 来源：v006 v010-3

## 文字与车牌

### 招牌、路牌、单位名
- 看什么：店招、公司牌、路名牌上的地名；按原文搜
- 指向：省 / 城市 / 街道
- 强度：路名牌、单位名强；店招里的地名中（连锁店、外地公司会误导）
- 反例：连锁品牌；以外地命名的店（"重庆火锅""沙县小吃"）
- 来源：通用；case001

### 标牌底部的发牌单位
- 看什么：交通标志、禁令牌、公示牌、施工牌角落的小字：〇〇市公安局交警支队、〇〇区城管、〇〇街道办
- 指向：市、区县，常直接给出行政区
- 强度：中（读得清就到区；跨区管辖的单位名不等于所在区）
- 反例：小字模糊易读错，要第二处印证
- 来源：v003（国外同类做法，国内标牌同样适用）

### 固话区号
- 看什么：招牌、广告、施工告示上的固话号码（手机号不对应地区）
- 指向：大致按首位数字分片——010 北京、02X 直辖市和特大城市（020 广州、021 上海、022 天津、023 重庆、024 沈阳、025 南京、027 武汉、028 成都、029 西安）；03 华北中原（河北、山西、河南）；04 东北和内蒙古；05 华东（江苏、山东、安徽、浙江、福建）；07 华中华南（湖北、湖南、广东、广西、江西）；08 西南（四川、贵州、云南、西藏）；09 西北（陕西、甘肃、宁夏、青海、新疆）。完整区号查表到地级市
- 强度：中（完整区号到市）
- 反例：先按数字分组判断区号位数；400/800 号码、手机号不对应地区；公司总部电话可能在外地；少数区号分片有例外（如 06 开头分属山东、广东、云南部分地区），以查表为准
- 来源：v003（方法）；分片规律为通用常识，引用前查表核实

### 车牌
- 看什么：第一个汉字是省级简称，第二位字母是地级市代码（A 多为省会，例外：青岛鲁B、深圳粤B、大连辽B、厦门闽D 等，查表）；底色：蓝牌小车、黄牌大车、渐变绿牌新能源小车、黄绿牌新能源大车、黑牌涉外和港澳入境车（粤Z）
- 指向：省 / 地级市
- 强度：街上多辆车一致时强；单辆、停车场、景区、酒店门口、高速服务区只算弱
- 反例：外地车在大城市、旅游区很常见；货运走廊车牌五湖四海；酒店、景区停车场里看不清的外地牌，不能拿来定地点
- 来源：case001 v011

## 车辆与交通

### 出租车颜色
- 看什么：车身主色（绿、黄、蓝白、红等）和配色方式
- 指向：城市级候选名单（例：绿色系出租车在四川多个城市常见，具体名单要现查，会随年份变）
- 强度：弱（单一来源）；和公交配色、地形组合后中
- 反例：同城常多色并存、换代频繁；重庆、西安、长治等地也有绿色系出租车；网约车不算
- 来源：v006

### 公交车顶和车身配色（俯拍看得清）
- 看什么：公交车顶颜色、车身主色、腰线、车尾图案（俯拍放大后常只剩色块，也够用）
- 指向：逐城比对的指纹（先用出租车等缩到几个城市，再用公交配色区分）；**直辖市、大地级市内部能分到区县**：主城和远郊区县的公交公司不同，配色差别大
- 怎么查：先确认主城常见配色；对不上就按"<城市> <颜色描述> 公交"搜图，从结果图的线路牌、公司名拿区县名（先落到区县再用）；最后把候选区县的公交图逐张比车尾、腰线
- 强度：中（v006、v014 两个来源；能从整个市缩到一两个区县）；有线路牌、公司名时强
- 反例：同城多种涂装并存、换代频繁；广告车身盖住原色；跨区县线路的车会开到别的区；搜图前几页没出现不等于没有
- 来源：v006 v014

## 基础设施

### 电气化铁路接触网支柱：单侧还是两侧
- 看什么：铁路旁一排杆子顶上伸出三角形腕臂、挂两三根不平行的线（承力索、接触线）。只在轨道一侧 → 多为单线；两侧都有或有横跨门架 → 双线
- 指向：电气化铁路；单线电气化铁路占比小，可大幅缩圈（再配地区线索，用 `osm.py` 或铁路线路图列候选线）
- 强度：中
- 反例：远处或低处看，另一侧支柱可能被树、路堤挡住；车站和桥隧处结构不同；"单线 = 老线"不成立
- 来源：v011

### 输电线分裂导线根数
- 看什么：铁塔横担下每相导线几根一束（中间有间隔棒）
- 指向：电压等级。常见：单根 ≈220 kV 以下，2 根 220–330 kV，4 根 500 kV，6 根 750 kV 或 ±800 kV 直流，8 根 1000 kV
- 强度：弱（单独只说明电网等级）；和铁路、河流、高速求交后中
- 反例：特殊设计；远处根数易数错；同走廊多回线路叠在一起
- 来源：v011 v010-3

### 城市特殊交通设施组合
- 看什么：跨江客运索道（两三根承载索靠近平行 + 牵引索，从岸边站房斜伸向对岸）、公轨两用桥（双层桁架，下层走轨道交通）、轻轨穿楼、城市长扶梯、高铁高架桥
- 指向：设施各对应一串城市，同时出现两三种时取交集（跨江客运索道、公轨两用桥、江边陡山同框时，全国通常只剩一两座山地江城），交集用网页搜索逐项核实，不凭印象
- 强度：中（组合后可到城市）
- 反例：跨江高压线（高塔、绝缘子、近水平）、斜拉桥拉索（塔顶扇形）、码头吊机钢缆会被误认成索道；武汉、南京等地的公铁两用桥结构相似但颜色、地形不同
- 来源：v005 v010-3

### 户户通卫星小锅
- 看什么：农村、城中村屋顶直径 35–60 cm 的小锅
- 指向：朝向对应经度：东部城市朝西南（约 215°–227°），西部朝南或东南（数值表见 `sky.md` 第 5 节）
- 强度：中（方位角读得准时能卡经度范围）
- 反例：单位和有线电视站的大锅对别的卫星；偏馈锅面倾角不等于仰角
- 来源：sky.md 推算；v001（锅当指南针的做法）

## 气候与物候（必须配月份）

### 冬季照片里成片常绿阔叶
- 看什么：12–2 月的照片里，行道树、绿化带、城边山坡是否大面积绿色（香樟、女贞、桂花、榕树一类）
- 指向：亚热带常绿阔叶林区，大致秦岭—淮河以南
- 强度：有可靠月份时中（排除半个中国）；没有月份时弱
- 反例：北方城市也有松柏、大叶黄杨等常绿绿化（多为针叶或灌木）；**北方省份的秦岭以南地块冬季也常绿：甘肃陇南、陕西汉中和安康**；南方高海拔山区冬季会落叶积雪
- 来源：v006

### 冬季山地的颜色（远景、航拍）
- 看什么：冬季远景或高空照片里山体整体灰褐光秃，还是成片发绿
- 指向：灰褐 → 秦岭—淮河以北的温带山地；常绿 → 南方亚热带山地
- 强度：中（分南北，定不到省）
- 反例：大兴安岭北段、长白山等针叶林区冬天也深绿；西北干旱区四季都褐；南方高海拔冬季也枯黄；夏季照片不适用
- 来源：v012 v006

### 高空看到的白色水体
- 看什么：航拍、舷窗照片里水面均匀发白、没有反光
- 指向：结冰或冰上积雪 → 冬季日均温长期低于 0 ℃ 的地区，大致秦岭—淮河以北
- 强度：弱（配季节和山地颜色）
- 反例：盐湖、盐田、干涸湖底、浑浊泥沙水、太阳耀斑、薄云；南方寒潮时小水体也会短暂结冰
- 来源：v012

### 棕榈、椰树 → "中国热带"
- 看什么：成排椰树、棕榈科植物、热带景观
- 指向：候选必须列全：海南、广东南部（雷州半岛）、广西南部、**云南南部（西双版纳、德宏、红河等河谷）**、台湾南部；再往外是东南亚
- 强度：弱（只圈候选集）
- 反例：福建、四川、上海等地公园也人工种棕榈科；v010-6 AI 只搜海南广东，漏了云南，最后跳去越南
- 来源：v010-6 v002

### 垂柳 + 平静人工水体，无其他特征
- 看什么：垂柳、杂树、灌渠或鱼塘样水面，没有山、塔、路牌、建筑
- 指向：黄淮海平原省份（河南、河北、山东、安徽、江苏）为主
- 强度：弱（只到几个省；这类照片通常只能给区间）
- 反例：长江流域、西北绿洲灌区也常见垂柳和水渠
- 来源：v010-8

### 雾、低云
- 看什么：能见度低、天空灰白、远山只剩轮廓
- 指向：四川盆地城市（重庆等）冬半年常见
- 强度：弱（只加分，不定城市，更定不到节气）
- 反例：华北、长三角冬季雾霾天看起来一样；手机滤镜、逆光也会发灰
- 来源：v005

## 地形与水系

### 大江对岸直接起山、楼沿坡叠建
- 看什么：江面很宽，对岸一两公里内就是几百米的山，房子沿坡一层层往上
- 指向：山地江城（重庆主城、宜宾、泸州等川渝和长江上游城市）；排除长江中下游平原城市（武汉、九江、南京、芜湖）
- 强度：弱（排除一大片，不定城市）
- 反例：宜昌等城市对岸也有近山；雾会把远山"拉近"，看山脚是否直接接城区
- 来源：v005

### 两河交汇的山地城市
- 看什么：城区跨在两条河交汇处，四周是山
- 指向：川渝和西南常见格局（重庆、宜宾、泸州等）；具体城市靠交汇角、江心洲、桥位、河宽区分（`corridors.md` 第 6 节模板比对）
- 强度：弱（格局常见）
- 反例：江心洲和岸线随水位、工程变化，注意卫星图年份
- 来源：v006

### 宽阔浑黄的大河 + 低矮密集的碎沟壑
- 看什么：河宽几百米、水色土黄；两岸山不高但被冲沟切成树枝状，植被稀少，坡上有梯田
- 指向：黄河中游黄土高原河段（晋陕峡谷一带）及陕北、晋西、陇东支流
- 强度：中（到黄土高原 + 黄河，要配走向和两岸地形到河段）
- 反例：汛期长江、金沙江也黄，但两岸分别是平原和高山峡谷；无定河、延河等支流同样浑黄，但窄得多
- 来源：v008

### 峡谷里蓝绿色的黄河水面
- 看什么：黄土或红砂岩峡谷中，水色清澈蓝绿、不见泥沙的宽阔河面
- 指向：黄河上游梯级水库库区（甘肃刘家峡、盐锅峡、八盘峡，青海李家峡，宁夏青铜峡等）
- 强度：弱（只到"上游库区"一类河段）
- 反例：季节、光线、无人机滤镜都会改变水色；v010-2 AI 靠这一条选了最有名的库区，差 7 km
- 来源：v010-2

## 待补：同类城市之间的街景指纹

同一盆地、同一省里格局相近的几座城市，街景层面的区分线索还没积累（护栏颜色和样式、公交站台、路缘石、交通标志杆、路灯造型、住宅外立面配色）。库里没有之前，遇到"几座城都像"就现场抽样比：

```bash
python3 scripts/baidu_pano.py sample --bbox <城市A 城区 s,w,n,e> --n 24 --out cityA.jpg
python3 scripts/baidu_pano.py sample --bbox <城市B 城区 s,w,n,e> --n 24 --out cityB.jpg
```

- 只比市政统一采购、全城一致的东西（护栏、站台、标志杆），不比店招、树、车。
- 百度街景多是几年前采集的，护栏这类设施会换代；样本年份和照片年份差得多时降一档。
- 抽样比出的差异，要在三座以上城市、两次以上独立抽样里都成立，才能写进本节。

## 城市形态

### 天际线里没有写字楼群和超高层
- 看什么：画面里全是住宅高层，没有玻璃幕墙写字楼群和超高层地标
- 指向：地级市老城、县城，不是省会核心区
- 强度：弱
- 反例：省会老城区、郊县也这样；照片只拍到一个方向；拍摄者可能就站在城里最高的楼上
- 来源：v006

### 瓷砖外墙厂房 + 成排空调外机，紧挨新建超高层（珠三角）
- 看什么：六到八层厂房，外墙米黄、黄绿色小方块瓷砖，窗边挂满空调外机；旁边或背后有新建玻璃幕墙高楼
- 指向：深圳、东莞等地"工业区旧改"片区，老厂房还没拆、周边已起新楼
- 强度：弱（提示珠三角，不能单独定城市）
- 反例：苏州、宁波等长三角老工业区也有类似厂房，瓷砖颜色和空调外机密度通常不同
- 来源：case001
