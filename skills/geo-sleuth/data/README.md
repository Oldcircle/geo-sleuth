Notes:

- The five Wikipedia-sourced China/world tables are factual data scraped and compiled from the tables in the corresponding articles. Wikipedia text is licensed under CC BY-SA 4.0; these five tables are released under the same license, with attribution to Wikipedia and its editors.
- The `letter_notes_unverified` block under the `渝` (Chongqing) entry in `cn_plates.json` (municipality plate letter zones) does not come from Wikipedia; it comes from a general-knowledge table and is unverified. `clues.py` marks it unverified in its output.
- `country_names.json` is a hand-compiled mapping table; the keys of `en2zh` match the English spellings used in the other tables, and `aliases` maps short names, traditional-character names, former names, and English abbreviations to `en2zh` keys.
- **India tables.** Wikipedia sources are pinned to a revision (`oldid=`) rather than the live page: the live language table was vandalised on the day these were built, so `clues.py update` re-reads exactly the revision that was checked; bump the oldid deliberately after reviewing a newer revision. `in_std_codes` is parsed from the OCR text layer of the 2003 National Numbering Plan PDF with `pdftotext -layout` (poppler-utils; `update` stops with an install hint if it's missing). It is a Government of India publication; we take only the factual code list and know of no explicit licence on it, so treat that part as "facts from a public government document" rather than CC-licensed. Some codes have been renumbered or split since 2003 and LDCA/SDCA names use 2003 spellings (Bhir, Panji, Trichur); `clues.py` resolves states from the telecom circle, then by matching SDCA/LDCA names against RTO districts and capitals, then a small curated spelling map (`IN_LDCA_STATE`); border SDCAs it can't resolve come back as several candidate states. Additional-language and script data for a few languages missing from the scheduled-language table (English, Mizo, Khasi, Garo, Kokborok, Bhoti, Chhattisgarhi) is a small hand-written supplement in `clues.py` (`IN_SCRIPT_SUPPLEMENT`).
- The Andaman and Nicobar Islands have no RTO table in the source, so `AN` plates resolve to the UT only. PIN prefixes reach state level, not district; there is no PIN → post-office directory here.
- This directory contains no OpenStreetMap data; `gazetteer.py` and `osm.py` query Overpass live.

Source names and quoted source notes stay in their original language. Maintained annotations (including curated driving-side notes and unverified municipality hints) are in English; the agent explains source evidence in the user's language.
